# Expense Tracker & Analytics

A Python-based Expense Tracker & Analytics application that allows users to register, log in, manage their financial transactions, and analyze their spending using SQLite, Pandas, and Matplotlib.

## Features

- User Registration
- User Login
- Add Transactions
- View Transactions
- Update Transactions
- Delete Transactions
- Logout
- Transaction Analysis using Pandas
- Data Visualization using Matplotlib
- SQLite Database

## Technologies Used

- Python
- SQLite
- Pandas
- Matplotlib
- Git
- GitHub
